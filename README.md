# Jute Pest Image Classification

This project explores image-based classification of jute pests using the Jute Pest Dataset.

- Prepared and augmented images for model training.
- Fine-tuned and compared ResNet-50, ResNet-101, EfficientNet-B0, VGG16, and DenseNet-201 for 17-class classification.
- Evaluated model performance on the training, validation, and test sets.

# 黄麻害虫图像分类

本项目使用黄麻害虫图像数据集，探索基于图像的害虫分类。

- 整理并增强图像数据，用于模型训练。
- 微调并比较 ResNet-50、ResNet-101、EfficientNet-B0、VGG16 和 DenseNet-201，对 17 类害虫进行分类。
- 评估模型在训练集、验证集和测试集上的表现。
